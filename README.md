# 神奇悬浮窗（手机信息悬浮窗）

> 实时监测电池温度与功耗的 Android 悬浮窗工具
> 版本: 1.93 | 最低支持: Android 14 (API 34)

────────────────────────────────────────

功能特性
────────────────────────────────────────

  [温度] 实时温度显示
         悬浮窗显示当前电池温度(℃)，读取 Android 标准 BatteryManager API

  [功耗] 功耗监测
         显示整机实时功耗(W)，充电为正、放电为负

  [自定义] 高度自定义
         可调节字体大小、背景颜色、字体颜色、透明度、圆角曲率

  [屏幕] 横竖屏智能适配
         悬浮窗在横竖屏下均可自由拖拽，边界智能钳位不超出屏幕

  [后台] 隐藏后台模式
         开启后按 Home/返回键自动移除任务卡片，防止被划掉(悬浮窗继续运行)

  [自启] 开机自启动
         仅当上次退出前悬浮窗开着时才自动恢复

  [保活] 进程保活
         前台 Service(常驻通知) + 15 分钟心跳 + 不可见覆盖层 + JobScheduler 兜底；
         无障碍保活由系统绑定进程提升优先级(不读取屏幕内容)，锁屏不易被杀；
         提供电池优化白名单状态提示与国产 ROM 自启动一键跳转

  [更新] 自动更新检测与安装
         打开应用自动检测新版本，可在 App 内下载(圆形进度)并安装，也可忽略

  [锁定] 双击锁定
         双击悬浮窗锁定/解锁拖拽位置，独立开关控制

  [主题] 主题外观
         跟随系统 / 浅色 / 深色三种模式，Material Design 3 设计语言

  [家人] 家人位置共享
         输入同一个 6 位家庭码即可互相查看位置，地图展示家人位置、精度与更新时间；
         按需获取、先粗后精，室内自动启用 WiFi 指纹定位(10~30 米)；可查看家人电量
         (按需请求，不做周期上报)，可给成员加本地备注、可退出家庭。后台常驻靠无障碍
         保活(由系统绑定进程，无需额外常驻通知)；可单独关闭「允许家人请求我的位置与电量」

  [提醒] 家人到达/离开提醒
         给常用地点(如学校、公司)设地点与半径，家人到达或离开时收到一条通知
         (如「ma 到达 学校」)；地点与判定状态只存本机、不上传。
         注意：需家人位置共享处于开启状态；开启后会按检查频率(默认 10 分钟)定时请求
         家人位置，会增加对方设备的定位唤醒与耗电，关闭总开关即停止；这类定时任务
         可能被系统推迟，提醒时刻或比设定频率略晚

  - Android Studio / JDK 17+ / Android SDK 36+
  # 仓库内 gradle.properties 写死了作者本机的 JDK 路径(org.gradle.java.home)，
  # 换机器构建时请在用户级 ~/.gradle/gradle.properties 覆盖为你的 JDK 17+ 路径

  ./gradlew.bat assembleRelease --no-configuration-cache
  # 模拟器(雷电 x86_64)联调时追加 -PdevEmulatorAbi（产物含 x86_64，仅联调用，不发布）

使用说明
────────────────────────────────────────

  1. 安装 APK 后打开应用
  2. 开启悬浮窗权限
  3. 忽略电池优化
  4. [保活] 在「关于」页开启自启动（厂商设置），加入白名单
  5. 点击「启动悬浮窗」
  6. 拖拽可移动到任意位置
  7. [自启] 开启「开机自启动」让应用智能判断开机后是否自动恢复
  8. [提醒] 家人页 → 「地点提醒」→ 打开总开关 → 「新增地点」填名称与经纬度（可点
     「取家人上次位置」一键填入）、半径 100~5000 米、选监视哪些家人；家人进入/离开
     该地点时会收到通知。开启期间会按检查频率定时请求家人位置做判定，注意对方耗电
